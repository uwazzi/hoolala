# Logos and pixel art

- **hoolala-lcd-icon.svg**: the app icon. A pixel "!" in `lcd-ink` on an `lcd-bg` screen inside an ink frame, with two tiny hills. 32 x 32 grid, scale by whole multiples only (`image-rendering: pixelated`).
- **pixel-terrain.svg**: the hills, sun and pine drawn on a pixel grid, in `lcd-ink`. Used on home and every end-of-session screen.

The wordmark is set in type: HOOLALA! in Silkscreen Bold, uppercase, `lcd-ink` on `lcd-bg` (or `lcd-selected-ink` on an ink bar). Single ink: recolour only to another LCD token. The old purple marks (icon, small icon, character) from version 1 are retired.
